FOCUS EARTH v8 — Android PWA対応版

GitHubで新規Publicリポジトリを作成し、このフォルダの中身（index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png）をリポジトリのルートにアップロードします。Settings > Pages > Deploy from a branch > main / (root) を選択します。公開されたHTTPS URLをAndroid Chromeで開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選択します。

注意: 旧バージョンと同じURL/ブラウザの保存領域なら記録を引き継げる設計です。URLを変える場合は旧アプリからバックアップを取得する必要があります（旧版には書き出し機能がないため別途移行対応が必要です）。アプリの削除やブラウザデータ消去で記録が失われる可能性があります。定期的にJSONバックアップを保存してください。画面ロック中の終了音は保証されません。
